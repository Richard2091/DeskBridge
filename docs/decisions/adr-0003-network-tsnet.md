# ADR-0003：组网内置 Tailscale（tsnet），可切换到自建 Headscale

- 状态：**已接受（2026-10-06）**。技术验证（任务 21）证明 Windows 上的 `tsnet` 登录、访问、`WhoIs` 身份识别都可用，见 [spikes/results.md](../../spikes/results.md)
- 日期：2026-10-06
- 补充（2026-10-07）：Tailscale 是连接层的第一种实现，上层不直接依赖它，见 [ADR-0007](adr-0007-pluggable-connection-layer.md)

## 背景

原型最初用 SSH 反向隧道，不稳定；后来改为在两台设备上分别安装 Tailscale，已验证可用（Linux 服务器 ↔ Windows，经香港中继，约 230ms）。目标是让用户不用单独装组网软件，登录账号后就能看到并连接自己的设备，个人使用免费。

## 决定

1. **默认：** 程序内置 `tsnet`，使用 Tailscale 官方控制服务器。用户通过 OAuth（Google、GitHub、Microsoft 等）登录。
2. **可替换：** 控制服务器地址可配置为自建的 **Headscale**（BSD-3 开源）。
3. **中继：** 直连失败时走公共 DERP 中继。自建中继暂时搁置（2026-10-07），恢复时优先用 Tailscale peer relay，见 [ADR-0006](adr-0006-feature-tiers-and-lan-scope.md)。
4. **身份：** 用 `tsnet` 的 `WhoIs` 识别请求来源的账号和设备，取代原型的共享密钥。
5. **WireGuard 直连：** 作为后续的第二种传输方式，自带配对和密钥。

## 已知限制

- **“永久免费”取决于 Tailscale 的政策。** 据第三方报道，2026 年 4 月起个人版免费支持 6 个用户、设备数量不限（以 Tailscale 官网为准）。条款可能再变，Headscale 是保底方案。
- **对称 NAT 下直连困难。** 已实测：Windows 在运营商 NAT（对称型）后面，打洞失败，只能走中继。命令和截图不受影响，远程画面会卡顿，自建中继可以改善。
- **和已安装的 Tailscale 客户端共存：** 内置节点是独立节点，同一设备会出现两个条目。（已验证：两者可以同时运行）
- **出口网络限制：** 某些网络对 Tailscale 控制服务器或 UDP 有限制，需要用自建方案。（待验证）

## 必须考虑的网络场景

设计和测试都要覆盖下面的场景。除注明“已验证”外，都是待验证。

| 场景 | 预期的连接方式 | 要做的事 |
|---|---|---|
| 同一局域网 | `tsnet` 发现对方的局域网地址，直接连接，不经过中继 | 验证局域网内确实直连；客户端显示“局域网直连” |
| 跨网络，能打洞 | 点对点直连 | 显示“直连” |
| 跨网络，对称 NAT 等无法打洞 | 经 DERP 中继。**已验证**：Linux ↔ Windows 经香港中继，约 230ms | 显示“中继”和中继位置；建议自建中继 |
| 中国大陆网络 | 官方 DERP 都在境外，延迟高；控制服务器可能不稳定。**已验证**：跨境经公共中继约 0.4 Mbps，不能看画面 | 只承载工具类功能；自建中继暂时搁置（ADR-0006） |
| 只允许 HTTPS（443 端口）的企业或学校网络 | DERP 走 HTTPS，理论上可以穿过 | 验证 |
| 局域网能通，但连不上外网 | 控制服务器不可达。已经连接的设备能否继续通信、能维持多久，需要验证 | 局域网内自建 Headscale + DERP；或使用后续的 WireGuard 直连模式（任务 19） |
| 网络切换（Wi-Fi ↔ 有线、睡眠后唤醒、换 IP） | `tsnet` 应自动重新建立连接 | 验证恢复所需时间；协议层的请求要能重试 |
| 设备上已经装了 Tailscale | 两个独立节点。**已验证**可以共存 | 设备列表中把两者识别为同一台设备（待设计） |

客户端（命令行、MCP、桌面界面）都要显示每台设备当前的连接方式（局域网直连、直连、中继及中继位置）和延迟，方便判断远程画面等功能是否可用。

## 未采用的方案

- **SSH 反向隧道：** 不稳定，原型中已放弃。
- **Cloudflare Tunnel：** 面向 HTTP 服务发布，原始 TCP 需要额外的本地代理，不适合设备间互访。
- **只依赖系统已安装的 Tailscale：** 用户需要额外安装和配置，体验差。作为兼容模式保留：检测到系统 Tailscale 时也可以使用它。

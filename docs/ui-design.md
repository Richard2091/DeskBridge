# 界面与交互设计

> 状态：初版设计稿（任务 27），2026-10-08。可点击原型在 `ui/prototype/`，用浏览器直接打开 `ui/prototype/index.html`，不需要后端。
> 原型只用来确认布局和交互，Flutter 客户端（任务 12、25）按本文重新实现，不复用原型代码。
> 初版范围见 [ADR-0009](decisions/adr-0009-first-release-scope.md)：先做出能用的初版，在实际使用中再更新优化。初版不做的功能，设计记录在第 8 节。

## 1. 设计原则

1. **一屏只做一件事。** 每个页面只放完成当前任务需要的内容，主要操作不超过 5 个。次要信息放进展开器、右侧抽屉（手机上是底部面板）或弹出面板。
2. **留白和分层。** 间距按 4 的倍数：页面边距 32（窄窗口 24，手机 16），区块间隔 28，卡片内边距 20。内容最大宽度 1040（设备页 1100，设置 720），宽屏不铺满。
3. **状态一眼可见，细节按需展开。** 设备行和设备页顶部只显示一条最重要的状态（AI 操作中、本地用户在用、经中继等），点击才展开说明。
4. **AI 在做什么必须看得见、停得住。** AI 操作桌面时用紫色标识，提示条上随时可以接管或停止（ADR-0005）。
5. **按连接方式组织设备。** 设备页按 Tailscale、局域网等连接方式横向切换，每种连接方式一页，自己显示连接状态；DeskBridge 没有自己的账号（ADR-0009）。
6. **全部中文。** 按钮、菜单、选项不出现英文；产品名、工具名（如 `proc.exec`）、命令和路径除外。

参考：Tailscale 客户端（双栏、设备列表只放关键信息）、Fluent 2 和 Material 3 的间距与窗口尺寸类别。用户提出参考网易 UU 远程、ToDesk：UU 远程的公开设计资料没有查到，独立远程窗口的做法按用户描述设计，未核实。

## 2. 信息结构

### 2.1 桌面窗口

```
┌ 标题栏 ──────────────────────────────────────────────────────────┐
│ 品牌 DeskBridge                                  远程窗口 2 │ — ☐ ✕ │
├ 侧栏 ──┬ 内容 ───────────────────────────────────────────────────┤
│ 设备    │                                                       │
│ 操作记录│                  当前页面                              │
│         │                                                       │
│ 设置    │                                                       │
└────────┴───────────────────────────────────────────────────────┘
```

- **标题栏**（高 46，可拖动窗口）：左边品牌；右边“远程窗口 N”（只在有打开的远程窗口时出现）；最右是窗口按钮。不放连接状态、搜索和头像。
- **侧栏**（宽 196，窄窗口 60 只显示图标）：设备、操作记录；设置放在最下面。

### 2.2 设备页：按连接方式切换

```
设备                                         [搜索设备] [添加设备]
 Tailscale ● 7 │ 局域网 ● 2 │ ＋
━━━━━━━━━━━━━━┷━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
● 已连接  user@example.com · 本机 100.64.0.1                 [设置]
┌──────────────────────────────────────────────────────────────┐
│ ▢ my-laptop  本机          可被其他设备和 AI 访问          › │
│ ▢ win-pc  AI 操作中        局域网直连        ▂▄▆ 4 毫秒     › │
│ ▢ old-laptop  延迟高       中继（东京）      ▂   186 毫秒   › │
│ › 还有 2 台离线或未安装 DeskBridge 的设备                    │
└──────────────────────────────────────────────────────────────┘
```

- 顶部一排标签横向切换连接方式，每种连接方式一页。标签上显示名称、状态点（绿：已连接或已开启；灰：未登录或已关闭；红：已断开）和设备数；最后的“＋”是“添加连接方式”（WireGuard 直连、自建中继：后续支持）。默认显示 Tailscale；从设备页返回时回到这台设备所在的连接方式。
- 标签下是这种连接方式的状态条：状态、账号或本机地址，右侧是“立即重试”（断开时）和“设置”。
- 下面每台设备一行：图标和状态点、名称和最重要的一条状态、系统、路径（局域网直连 / 跨网直连 / 中继）、延迟；悬停时显示终端、文件、桌面快捷按钮。离线和未安装 DeskBridge 的设备折叠在列表最后一行“还有 N 台……”。
- **Tailscale** 页只放同一 Tailscale 账号的设备。未登录时不显示状态条和设备列表，只显示登录组件：“登录 Tailscale”按钮和“使用自建控制服务器（Headscale）”链接。
- **局域网** 页放同一局域网中发现、不在 Tailscale 里的 DeskBridge 设备，未配对的设备行右侧是“配对”按钮。局域网发现关闭时不显示列表，只显示“开启局域网发现”。
- 同一台设备在多个网络里只显示一次，放在 Tailscale 页（按 DeskBridge 设备 ID 合并）。
- 搜索只筛选当前页；当前页没有结果、另一种连接方式里有匹配时，提示“局域网中有 N 台匹配”，点击切换过去。
- 手机上标签平分宽度，设备行只保留名称、系统和延迟。

### 2.3 页面

| 页面 | 地址 | 内容 |
|---|---|---|
| 设备 | `#/devices` | 按连接方式横向切换，每台设备一行，见 2.2 |
| 设备页 | `#/devices/<设备>/<标签>` | 头部（名称、状态、连接方式 · 路径 · 延迟、远程画面按钮、更多）、一条状态提示、4 个标签：概览、终端、文件、桌面（截图 / 界面元素） |
| 操作记录 | `#/activity` | 按天分组的列表；分段筛选（全部、AI、人），设备和结果在“筛选”弹出面板里；点一条打开详情抽屉（调用链、结果、参数） |
| 设置 | `#/settings/<分区>` | 通用、外观、本机、桌面控制权、连接方式、AI 接入、关于 |
| 远程窗口 | 独立窗口 | 每台设备一个窗口，见 3.7 |

设置中的“连接方式”：Tailscale（账号、退出登录、控制服务器地址可改为 Headscale、授权密钥）；局域网（开关“在局域网中发现设备并允许配对”、已配对设备和取消配对）；WireGuard 直连和自建中继标“后续支持”。“AI 接入”给本机的 AI 客户端提供 MCP 配置，用来控制其他设备。

### 2.4 手机（安卓控制端）

- 底部 3 个标签：设备、记录、设置。
- 设备页、设置分区是二级页面，左上角返回。
- 抽屉和弹出面板变成底部面板；远程画面全屏显示在应用内（手机上不做多窗口）。

### 2.5 浮层

| 浮层 | 用途 | 关闭 |
|---|---|---|
| 弹出面板 | 筛选、终端历史和选项、画质、远程窗口列表 | 点外面、Esc |
| 抽屉（右侧 420 宽） | 操作详情、文件预览、界面元素属性 | 点外面、Esc、关闭按钮 |
| 对话框 | 需要决定的事：接管、停止 AI、添加设备、局域网配对 | Esc、取消 |
| 提示消息 | 操作结果，3.8 秒后消失 | 自动 |

Esc 依次关闭：菜单 → 弹出面板 → 抽屉 → 对话框 → 应用内远程画面。

## 3. 关键流程

原型右侧“原型控制台”的“流程与页面”可以直接跳到下面每个流程。

1. **首次启动：** 直接进入设备页，没有向导。Tailscale 页显示“登录 Tailscale 后，同一账号下的设备会自动出现在这里”和“登录 Tailscale”按钮 → 在浏览器中登录 → 标签变为已连接并列出设备。局域网页不需要登录，直接显示发现的设备。登录服务器连不上时显示错误码 `control_unreachable`，可以重试。设备名称、开机自启在“设置 → 本机 / 通用”中修改。
2. **添加设备：** 设备页“添加设备”→ 按电脑、服务器、手机给出安装方法 → 二选一：用同一 Tailscale 账号登录（自动出现），或在同一局域网中配对。
3. **执行并取消命令：** 设备页“终端”→ 输入命令回车 → 输出实时显示，状态栏显示运行时间 → “取消”结束进程树。历史和选项（超时、工作目录）在弹出面板里。
4. **AI 操作中：** 设备行和设备页顶部显示“Claude Code 正在操作桌面”，带“接管”“停止”。停止有三种：紧急停止、停止并结束它启动的进程、只接管鼠标键盘。
5. **本地用户抢回桌面：** 本地用户一动鼠标键盘，AI 的前台输入立即中断（`preempted`），提示条变成“本地用户正在使用”，本地停止操作 3 秒后 AI 继续（ADR-0005）。
6. **断线与重连：** Tailscale 标签的状态点变红，状态条显示“已断开 · 正在重连（第 N 次）”，带“立即重试”；列表中的设备变灰、状态“未知”。设备概览显示上次的信息并标明时间，其他标签页显示“暂时无法连接”。局域网页不受影响。
7. **远程画面（独立窗口）：** 设备页“远程画面”→ 新开一个窗口，每台设备一个，可以同时打开多台 → 主窗口标题栏出现“远程窗口 N”，可以切换或断开；设备页按钮变成“切换到远程窗口”。窗口顶部一条工具栏：设备名、路径和延迟、控制状态、接管或释放、画质与显示器、Ctrl+Alt+Del、全屏、断开。默认只观看，点“开始控制”或“接管”后才发送鼠标键盘。设置“通用 → 远程画面 → 打开方式”可以改为在主窗口中打开。不是局域网直连时不开放，提示改用截图（ADR-0006）。
8. **高延迟设备（中继）：** 状态提示“经中继连接，延迟较高 · 远程画面不可用”，展开后说明原因和“重新探测”。
9. **离线设备：** 折叠在列表最后一行“还有 N 台……”；设备页显示最后在线时间。
10. **未安装 DeskBridge 的设备：** 在 Tailscale 里但没有运行 DeskBridge，同样折叠；设备页显示安装命令。
11. **局域网配对：** 局域网页里未配对的设备行显示“配对”→ 对话框提示“在对方设备上打开 DeskBridge，会显示 6 位配对码”→ 输入配对码 → “已配对，以后自动连接”，设备行变为可用。已配对设备的“更多”菜单里可以取消配对，“设置 → 连接方式”里也可以。

## 5. 视觉规范

### 5.1 主题

内置三套主题，每套都有浅色和深色，可以跟随系统。默认“清爽”。

| 主题 | 特点 | 强调色（浅 / 深） | 圆角（中 / 大 / 特大） |
|---|---|---|---|
| 清爽 | 白色卡片、浅灰底、紫蓝强调色 | `#5b5bd6` / `#7c7cf0` | 8 / 12 / 16 |
| 黑白 | 黑白灰，几乎没有阴影，靠线条分层 | `#0a0a0a` / `#ededed` | 8 / 10 / 12 |
| 柔光 | 渐变背景、半透明毛玻璃面板、蓝紫渐变按钮 | `#3b6cf6` / `#6d8dff` | 11 / 16 / 20 |

完整取值见 `ui/prototype/css/theme.css`。

| accent / accentSoft | 主按钮、选中、链接 | `#5b5bd6` / `#ededfc` | `#7c7cf0` / 15% 透明 |

每个状态色都有对应的浅底色（`*Soft`），用于标签和提示条背景。

### 5.3 文字、间距和尺寸

- 字体：Windows 用 Segoe UI Variable / Segoe UI + 微软雅黑 UI；安卓用系统字体（思源黑体）。等宽：Cascadia Mono，中文回退到 Noto Sans Mono CJK。
- 字号：正文 14，次要 12.5–13，页面标题 24（手机 22），设备名 22，区块标题 13（次要色）。
- 间距：页面边距 32 / 24 / 16（宽 / 窄 / 手机），区块间隔 28，卡片内边距 20，列表行 14×18。
- 控件高度：按钮 30（小 26，大 40），输入框 32，标题栏 46。
- 阴影：清爽三级（小、中、大）；黑白只用 1 像素描边；柔光用大而淡的阴影加 20 像素模糊。

### 5.4 窗口尺寸

| 类别 | 宽度 | 布局 |
|---|---|---|
| 展开 | ≥ 1100 | 侧栏带文字，标题栏完整 |
| 中等 | 600–1100 | 侧栏只有图标；标题栏的“远程窗口”只显示图标 |
| 紧凑 | < 600 | 手机布局：底部标签栏，抽屉变成底部面板 |

分界值是按原型（1280、940、390 三种尺寸）定的，待在 Flutter 中调整。

### 5.5 对应 Flutter

- `ThemeData`：`colorScheme` 用 accent、surface、text、bad 等生成；`useMaterial3: true`；字体按平台设置。
- `ThemeExtension<DeskTokens>`：放 Material 没有的变量：surface2、surface3、borderStrong、faint、ok、warn、info、ai 及各自的浅底色、codeBg、aiBg（渐变）、logoGradient、四档圆角、三档阴影、面板模糊。
- 三套主题 × 浅深色 = 6 组 `DeskTokens` 常量，设置里切换后立即生效。
- 柔光主题的毛玻璃用 `BackdropFilter`。在安卓或低性能设备上可以改为不透明面板（性能待验证）。
- 远程窗口固定用深色，不随主题变化。

## 6. 原型

- 位置：`ui/prototype/`。`index.html` 加载 `css/theme.css`（主题变量）、`css/app.css`（布局和组件）、`js/icons.js`（自绘图标）、`js/data.js`（示例数据，全部虚构）、`js/core.js`（状态、路由、外壳、浮层）、`js/devices.js`（设备首页、设备页、远程画面）、`js/pages.js`（操作记录、设置）。
- 风格样张：`ui/style-samples/index.html`（第一轮四种风格）、`ui/style-samples/refined.html`（最终三套主题的样张）。
- 右侧原型控制台：切换主题、明暗、窗口尺寸、场景、win-pc 的桌面控制权，跳到第 3 节的流程。
- 地址参数（方便截图）：`?theme=clean|mono|soft&mode=light|dark|system&size=desktop|narrow|phone&scenario=normal|loading|nologin|error|netdown&control=none|ai|local|human|paused&proto=closed`，页面用 `#/…`。另外：`modal=动作名`（如 `addDevice`；`modal=pairDevice&id=study-pc` 打开配对对话框），`sess=win-pc`（假装已打开远程窗口），`win=remote&dev=win-pc`（远程窗口本身）。
- 远程画面在浏览器里用 `window.open` 打开新窗口模拟独立窗口；浏览器阻止弹出窗口时改为在当前窗口显示。
- 第三版原型（含第 8 节的后续功能）在提交 `9067ca1` 中，需要时可以从 git 历史中查看。

| 设置 | 第 2.3 节设置页中的所有选项 |

### 7.2 命令（界面 → ui-core）

Tailscale 登录和退出；局域网发现开关、配对（提交配对码）、取消配对；读取设备列表；执行命令（流式输出）和取消；文件列表、读取、上传（进度）、下载、取消；截图；读取窗口和元素树、高亮元素、执行元素操作；接管、释放、紧急停止 AI（三种方式）；打开和关闭远程会话；查询操作记录（筛选、分页）；读取和保存设置。

### 7.3 事件（ui-core → 界面）

各连接方式的状态变化；设备上线、下线、路径和延迟变化；局域网发现新设备、配对结果；桌面控制权变化（包括被抢占）；新的操作记录；命令输出片段和结束；上传进度；远程会话状态。

### 7.4 错误码

界面需要区分处理：`ui_core_timeout`（后台没有响应）、`control_unreachable`（登录服务器连不上）、`pairing_failed`（配对码错误或过期，名称待定）、`not_paired`（局域网设备未配对，名称待定）、`preempted`（被本地用户抢占）、`control_busy`（控制权被占用）、`elevated_target`（目标是管理员窗口）、`unsupported_platform`（平台不支持）、`remote_not_available`（不是局域网直连，名称待定）。

## 8. 后续功能（初版不做）

下面的设计在第三版原型（提交 `9067ca1`）中做过，初版不做（ADR-0009）。在实际使用初版后再决定是否做、怎么做，届时再补进第 2–7 节。

- **访问权限（任务 17，ADR-0008）：** 侧栏增加“访问权限”页，按发起者分组（我本人、我的 AI、共享给别人），逐项开关查看屏幕、鼠标、键盘、剪贴板、执行命令、读写删除文件和文件范围、重启关机；预设完全访问、标准、只看。允许执行命令或键盘、同时限制文件时提醒“可以被绕过”。拒绝时返回 `permission_denied`，附缺少的权限。
- **发起端确认（ADR-0008）：** 我的 AI 要做危险操作（如删除文件）时，确认请求发到 AI 客户端、我的 DeskBridge 窗口或手机；标题栏显示“N 项待确认”；可以拒绝、允许一次、本次会话都允许，超时拒绝。规则在“设置 → 操作确认”中设置。
- **外部设备和他人共享：** 设备页增加“外部设备”标签；没有授予的标签页显示锁和“没有权限”。共享给别人用一次性邀请链接，可以设置有效期、随时撤销。
- **调用被控端的 AI：** 设备页增加“AI”标签：选 Agent、写任务，实时显示步骤，可以取消；概览里列出被控端的 Agent、MCP 服务器和 Skill。
- **全局搜索：** 标题栏中间的搜索框（Ctrl K），搜索设备、操作和页面。
- **WireGuard 直连、自建中继（任务 19、13）：** 作为新的连接方式标签出现在设备页，设置在“连接方式”中。

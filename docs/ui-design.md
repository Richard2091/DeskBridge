# 界面与交互设计

> 状态：设计稿（任务 27），2026-10-07。可点击原型在 `ui/prototype/`，用浏览器直接打开 `ui/prototype/index.html`，不需要后端。
> 原型只用来确认布局和交互，Flutter 客户端（任务 12、25）按本文重新实现，不复用原型代码。

## 1. 设计原则

1. **一屏只做一件事。** 每个页面只放完成当前任务需要的内容，主要操作不超过 5 个。次要信息放进展开器、右侧抽屉（手机上是底部面板）或弹出面板。
2. **留白和分层。** 间距按 4 的倍数：页面边距 32（窄窗口 24，手机 16），区块间隔 28，卡片内边距 20。内容最大宽度 1040（设备页 1100，设置 720），宽屏不铺满。
3. **状态一眼可见，细节按需展开。** 设备卡片和设备页顶部只显示一条最重要的状态（AI 操作中、本地用户在用、经中继等），点击才展开说明。
4. **AI 在做什么必须看得见、停得住。** AI 操作桌面时用紫色标识，提示条上随时可以接管或停止（ADR-0005）。
5. **不绑定某一种连接方式。** 界面上说“连接方式”，Tailscale 只是其中一种（ADR-0007）。
6. **全部中文。** 按钮、菜单、选项不出现英文；产品名、工具名（如 `proc.exec`）、命令和路径除外。

参考：Tailscale 客户端（双栏、设备列表只放关键信息）、Fluent 2 和 Material 3 的间距与窗口尺寸类别。用户提出参考网易 UU 远程、ToDesk：UU 远程的公开设计资料没有查到，独立远程窗口的做法按用户描述设计，未核实。

## 2. 信息结构

### 2.1 桌面窗口

```
┌ 标题栏 ─────────────────────────────────────────────────────────────────┐
│ 品牌 DeskBridge │      搜索设备、操作或页面  Ctrl K      │ 待确认 · 远程窗口 · 已连接 · 头像 │ — ☐ ✕ │
├ 侧栏 ──┬ 内容 ──────────────────────────────────────────────────────────┤
│ 设备    │                                                              │
│ 操作记录│                  当前页面                                     │
│ 访问权限│                                                              │
│         │                                                              │
│ 设置    │                                                              │
└────────┴──────────────────────────────────────────────────────────────┘
```

- **标题栏**（高 46，可拖动窗口）：左边品牌；中间全局搜索（命令面板，Ctrl K）；右边按需出现的提示：“N 项待确认”（有发起端确认时）、“远程窗口 N”（有打开的远程窗口时）、连接状态、头像菜单；最右是窗口按钮。
- **侧栏**（宽 196，窄窗口 60 只显示图标）：只放页面导航。设置放在最下面。
- **断线提示**：连接断开时在内容区顶部显示一条，带“立即重试”。

### 2.2 页面

| 页面 | 地址 | 内容 |
|---|---|---|
| 设备 | `#/devices` | 卡片网格：我的设备（只显示在线的，离线和未安装的折叠为一行）、外部设备 |
| 设备页 | `#/devices/<设备>/<标签>` | 头部（名称、状态、连接方式 · 路径 · 延迟、远程画面按钮、更多）、一条状态提示、5 个标签：概览、终端、文件、桌面（截图 / 界面元素）、AI（规划中） |
| 操作记录 | `#/activity` | 按天分组的列表；分段筛选（全部、AI、人、外部），设备和结果在“筛选”弹出面板里；点一条打开详情抽屉（调用链、结果、参数） |
| 访问权限 | `#/access` | 我自己（我本人、我的 AI）、共享给别人、别人共享给我；点一项打开权限抽屉；“共享给别人”“输入邀请链接” |
| 设置 | `#/settings/<分区>` | 通用、外观、本机、桌面控制权、操作确认、连接方式、AI 接入、关于 |
| 首次登录 | `#/welcome` | 5 步：欢迎 → 选择连接方式 → 浏览器登录 → 设置这台电脑 → 完成 |
| 远程窗口 | 独立窗口 | 每台设备一个窗口，见 3.7 |

### 2.3 手机（安卓控制端）

- 底部 4 个标签：设备、记录、权限、设置。
- 设备页、设置分区是二级页面，左上角返回。
- 抽屉和弹出面板变成底部面板；远程画面全屏显示在应用内（手机上不做多窗口）。
- 有待确认的操作时，顶部显示一条提示，点击打开确认面板。

### 2.4 浮层

| 浮层 | 用途 | 关闭 |
|---|---|---|
| 弹出面板 | 筛选、终端历史和选项、画质、连接状态、头像菜单 | 点外面、Esc |
| 抽屉（右侧 420 宽） | 操作详情、文件预览、界面元素属性、权限编辑 | 点外面、Esc、关闭按钮 |
| 对话框 | 需要决定的事：发起端确认、接管、停止 AI、添加设备、共享 | Esc、取消 |
| 命令面板 | 搜索设备、操作和页面 | Esc |
| 提示消息 | 操作结果，3.8 秒后消失 | 自动 |

Esc 依次关闭：命令面板 → 菜单 → 弹出面板 → 抽屉 → 对话框 → 应用内远程画面。

## 3. 关键流程

原型右侧“原型控制台”的“流程与页面”可以直接跳到下面每个流程。

1. **首次登录：** 欢迎 → 选择连接方式（Tailscale 账号，推荐；自建 Headscale；WireGuard 直连，规划中）→ 在浏览器中登录（可以复制登录链接）→ 设置设备名称、允许“我的 AI”在这台电脑上做什么、开机自启 → 显示发现的设备和 MCP 配置入口。登录服务器连不上时显示错误码 `control_unreachable`，可以重试或换一种方式。
2. **添加设备：** 设备页“添加设备”→ 按电脑、服务器、手机给出安装方法 → 新设备用同一种连接方式登录后自动出现，对话框里实时提示“正在等待新设备上线”。
3. **执行并取消命令：** 设备页“终端”→ 输入命令回车 → 输出实时显示，状态栏显示运行时间 → “取消”结束进程树。历史和选项（超时、工作目录）在弹出面板里。
4. **AI 操作中：** 设备卡片和设备页顶部显示“Claude Code 正在操作桌面”，带“接管”“停止”。停止有三种：紧急停止、停止并结束它启动的进程、只接管鼠标键盘。
5. **本地用户抢回桌面：** 本地用户一动鼠标键盘，AI 的前台输入立即中断（`preempted`），提示条变成“本地用户正在使用”，本地停止操作 3 秒后 AI 继续（ADR-0005）。
6. **断线与重连：** 标题栏连接状态变红，内容区顶部显示“Tailscale 连接已断开 · 正在重连（第 N 次）”；设备概览显示上次的信息并标明时间，其他标签页显示“暂时无法连接”。
7. **远程画面（独立窗口）：** 设备页“远程画面”→ 新开一个窗口，每台设备一个，可以同时打开多台 → 主窗口标题栏出现“远程窗口 N”，可以切换或断开；设备页按钮变成“切换到远程窗口”。窗口顶部一条工具栏：设备名、路径和延迟、控制状态、接管或释放、画质与显示器、Ctrl+Alt+Del、全屏、断开。默认只观看，点“开始控制”或“接管”后才发送鼠标键盘。设置“通用 → 远程画面 → 打开方式”可以改为在主窗口中打开。不是局域网直连时不开放，提示改用截图（ADR-0006）。
8. **高延迟设备（中继）：** 状态提示“经中继连接，延迟较高 · 远程画面不可用”，展开后说明原因和“重新探测”。
9. **离线或未安装 DeskBridge 的设备：** 首页折叠到“还有 N 台……”；设备页显示最后在线时间，或安装命令。
10. **外部设备：** 别人共享给我的设备单独分组；没有授予的标签页显示锁和“没有权限”，可以向对方申请。
11. **发起端确认危险操作：** 我的 AI 要删除文件时，确认请求发到发起的一方（AI 客户端、我的 DeskBridge 窗口或手机），显示命令、命中的规则、AI 的说明和剩余时间；可以拒绝、允许一次、本次会话都允许。没人处理时超时拒绝（ADR-0008）。
12. **设置访问权限：** 访问权限 → 选一个发起者 → 抽屉里选预设（完全访问、标准、只看）或逐项开关，设置文件范围和适用设备；允许执行命令或键盘、同时限制文件时显示“可以被绕过”的提醒。
13. **共享给别人：** 访问权限 →“共享给别人”→ 选设备、权限（默认“只看”）、有效期 → 生成一次性邀请链接，24 小时有效 → 对方接受后出现在“共享给别人”，可以随时修改或撤销。
14. **调用被控端的 Agent（规划中）：** 设备页“AI”→ 选 Agent、写任务 → 实时显示步骤，可以取消，断线后可以回来查看结果。
15. **命令面板：** Ctrl K 或点标题栏搜索框 → 搜索设备、操作、页面，回车执行。

原型控制台的“场景”和“桌面控制权”可以切换下列状态。

| 页面 | 正常 | 加载中 | 空 | 出错 | 连接断开 | 其他 |
|---|---|---|---|---|---|---|
| 设备首页 | 卡片网格 | 骨架卡片 | 只有本机 + “添加你的第一台设备” | “无法读取设备列表”，错误码，打开日志、重试 | 卡片变灰，状态“未知”，副标题说明 | 搜索无结果 |
| 设备页 · 概览 | 快捷操作 4 个、统计 3 个、最近操作 3 条、设备详情（折叠） | — | 暂无操作 | — | 显示上次的信息并标明时间 | 离线、未安装、版本较旧、合并显示的设备 |

| 设备页 · AI | 任务输入、步骤 | 进行中 | — | — | 同上 | 节点版本较旧；规划中 |
| 操作记录 | 按天分组 | 骨架行 | “还没有操作记录” | — | — | 筛选后为空 |
| 访问权限 | 三个分组 | — | “还没有共享给别人” | 保存失败（待设计） | 只读（待设计） | 外部用户已过期 |

桌面控制权的 5 种状态（空闲、AI 操作中、本地用户在用、我在远程操作、被控端已暂停）在设备卡片、设备页状态提示、概览统计和远程窗口中显示一致。

## 5. 视觉规范

### 5.1 主题

内置三套主题，每套都有浅色和深色，可以跟随系统。默认“清爽”。

| 主题 | 特点 | 强调色（浅 / 深） | 圆角（中 / 大 / 特大） |
|---|---|---|---|
| 清爽 | 白色卡片、浅灰底、紫蓝强调色 | `#5b5bd6` / `#7c7cf0` | 8 / 12 / 16 |
| 黑白 | 黑白灰，几乎没有阴影，靠线条分层 | `#0a0a0a` / `#ededed` | 8 / 10 / 12 |
| 柔光 | 渐变背景、半透明毛玻璃面板、蓝紫渐变按钮 | `#3b6cf6` / `#6d8dff` | 11 / 16 / 20 |

完整取值见 `ui/prototype/css/theme.css`。

### 5.2 颜色变量

| 变量 | 用途 | 清爽浅色 | 清爽深色 |
|---|---|---|---|
| page | 窗口底色 | `#f4f4f6` | `#0f0f12` |
| surface / surface2 / surface3 | 卡片、次级区域、输入框和悬停 | `#ffffff` / `#f8f8fa` / `#f1f1f4` | `#17171b` / `#131316` / `#1d1d22` |
| border / borderStrong | 分隔线、输入框边框 | `#e6e6ea` / `#d4d4da` | `#26262d` / `#34343c` |
| text / muted / faint | 正文、次要文字、提示文字 | `#18181b` / `#71717a` / `#a1a1aa` | `#ededf0` / `#9a9aa5` / `#63636e` |
| accent / accentSoft | 主按钮、选中、链接 | `#5b5bd6` / `#ededfc` | `#7c7cf0` / 15% 透明 |
| ok | 在线、成功 | `#16a34a` | `#34d399` |
| warn | 延迟高、被抢占、待确认 | `#d97706` | `#fbbf24` |
| bad | 失败、拒绝、断开、危险操作 | `#dc2626` | `#f87171` |
| info | 本地用户在用、进行中、我在控制 | `#2563eb` | `#60a5fa` |
| ai | AI 操作中（只用于 AI） | `#7c3aed` | `#a78bfa` |

每个状态色都有对应的浅底色（`*Soft`），用于标签和提示条背景。

### 5.3 文字、间距和尺寸

- 字体：Windows 用 Segoe UI Variable / Segoe UI + 微软雅黑 UI；安卓用系统字体（思源黑体）。等宽：Cascadia Mono，中文回退到 Noto Sans Mono CJK。
- 字号：正文 14，次要 12.5–13，页面标题 24（手机 22），设备名 22，区块标题 13（次要色）。
- 间距：页面边距 32 / 24 / 16（宽 / 窄 / 手机），区块间隔 28，卡片内边距 20，列表行 14×18。
- 控件高度：按钮 30（小 26，大 40），输入框 32，标题栏 46。
- 阴影：清爽三级（小、中、大）；黑白只用 1 像素描边；柔光用大而淡的阴影加 20 像素模糊。

### 5.4 窗口尺寸

| 类别 | 宽度 | 布局 |
|---|---|---|
| 展开 | ≥ 1100 | 侧栏带文字，标题栏完整 |
| 中等 | 600–1100 | 侧栏只有图标；标题栏的搜索框和提示只显示图标 |
| 紧凑 | < 600 | 手机布局：底部标签栏，抽屉变成底部面板 |

分界值是按原型（1280、940、390 三种尺寸）定的，待在 Flutter 中调整。

### 5.5 对应 Flutter

- `ThemeData`：`colorScheme` 用 accent、surface、text、bad 等生成；`useMaterial3: true`；字体按平台设置。
- `ThemeExtension<DeskTokens>`：放 Material 没有的变量：surface2、surface3、borderStrong、faint、ok、warn、info、ai 及各自的浅底色、codeBg、aiBg（渐变）、logoGradient、四档圆角、三档阴影、面板模糊。
- 三套主题 × 浅深色 = 6 组 `DeskTokens` 常量，设置里切换后立即生效。
- 柔光主题的毛玻璃用 `BackdropFilter`。在安卓或低性能设备上可以改为不透明面板（性能待验证）。
- 远程窗口固定用深色，不随主题变化。

## 6. 原型

- 位置：`ui/prototype/`。`index.html` 加载 `css/theme.css`（主题变量）、`css/app.css`（布局和组件）、`js/icons.js`（自绘图标）、`js/data.js`（示例数据，全部虚构）、`js/core.js`（状态、路由、外壳、浮层）、`js/devices.js`（设备首页、设备页、远程画面）、`js/pages.js`（操作记录、访问权限、设置、首次登录）。
- 风格样张：`ui/style-samples/index.html`（第一轮四种风格）、`ui/style-samples/refined.html`（最终三套主题的样张）。
- 右侧原型控制台：切换主题、明暗、窗口尺寸、场景、win-pc 的桌面控制权，跳到第 3 节的流程。
- 地址参数（方便截图）：`?theme=clean|mono|soft&mode=light|dark|system&size=desktop|narrow|phone&scenario=normal|loading|empty|error|netdown&control=none|ai|local|human|paused&proto=closed`，页面用 `#/…`。另外：`modal=动作名`（如 `addDevice`、`invite`、`demoConfirm`），`modal=grantee&id=bob`，`onb=1`（首次登录第几步），`sess=win-pc`（假装已打开远程窗口），`win=remote&dev=win-pc`（远程窗口本身）。
- 远程画面在浏览器里用 `window.open` 打开新窗口模拟独立窗口；浏览器阻止弹出窗口时改为在当前窗口显示。

## 7. 给 ui-core 的数据需求

界面需要 ui-core（任务 12，Go 子进程，经标准输入输出传 JSON）提供下列数据、命令和事件。字段名和格式在任务 4、12 中确定，这里只列内容。

### 7.1 数据

| 对象 | 字段 |
|---|---|
| 账号 | 显示名、邮箱、头像 |
| 连接方式 | ID、名称、状态（已连接、需要登录、断开、规划中）、账号、控制服务器、本机地址、设备数、最近同步时间、最近错误、重连次数 |
| 设备 | DeskBridge 设备 ID、名称、类型（台式机、笔记本、服务器、手机、存储）、系统、分组（我的、外部）、主人（外部设备）、是否本机、是否在线、最后在线时间、是否运行 DeskBridge、节点版本、是否可更新、连接方式、路径（局域网直连、跨网直连、中继及位置）、延迟、最近 10 分钟延迟、地址、桌面会话状态、显示器数量、运行方式、能力列表、合并来源、我被授予的权限（外部设备） |
| 桌面控制权 | 每台设备：持有者（无、AI、本地用户、远程人工）、持有者身份、开始时间、排队列表、是否被本地暂停 |
| 操作记录 | 请求 ID、时间、操作者（类型、名称、来自哪台设备）、目标设备、工具、摘要、结果（成功、失败、进行中、已取消、被抢占、被拒绝）、耗时、调用链、参数（已脱敏）、结果摘要、拒绝原因 |
| 访问权限 | 发起者（我本人、我的 AI、外部用户）、适用设备、各项权限、文件范围、按设备覆盖、有效期 |
| 确认请求 | ID、操作者、目标设备、工具、内容、命中的规则、AI 的说明、截止时间 |
| 确认规则 | 名称、说明、是否开启、等待时长 |
| 共享 | 我共享出去的（对象、设备、权限、有效期）、别人共享给我的、邀请链接 |
| 文件 | 名称、是否文件夹、大小、修改时间；文本预览 |
| 截图 | 时间、截取者、显示器、图片 |
| 窗口和界面元素 | 窗口列表（标题、程序、是否管理员）；元素树（类型、名称、自动化 ID、类名、位置、支持的操作、是否可用） |
| 被控端 AI 能力 | Agent（名称、版本、是否登录）、MCP 服务器（名称、工具数、状态）、Skill |
| 远程会话 | 设备、画质、帧率、码率、显示器、控制状态 |
| 设置 | 第 2.2 节设置页中的所有选项 |

### 7.2 命令（界面 → ui-core）

登录和退出（按连接方式）；读取设备列表；执行命令（流式输出）和取消；文件列表、读取、上传（进度）、下载、取消；截图；读取窗口和元素树、高亮元素、执行元素操作；接管、释放、紧急停止 AI（三种方式）；打开和关闭远程会话；读取和保存访问权限；回应确认请求（拒绝、允许一次、本次会话都允许）；创建、接受、撤销邀请；查询操作记录（筛选、分页）；读取和保存设置；调用被控端的 Agent 和取消。

### 7.3 事件（ui-core → 界面）

连接状态变化；设备上线、下线、路径和延迟变化；桌面控制权变化（包括被抢占）；新的操作记录；新的确认请求和过期；命令输出片段和结束；上传进度；Agent 步骤；远程会话状态。

### 7.4 错误码

界面需要区分处理：`ui_core_timeout`（后台没有响应）、`control_unreachable`（登录服务器连不上）、`permission_denied`（被控端权限不允许，附缺少的权限）、`preempted`（被本地用户抢占）、`control_busy`（控制权被占用）、`elevated_target`（目标是管理员窗口）、`unsupported_platform`（平台不支持）、`remote_not_available`（不是局域网直连，名称待定）。
